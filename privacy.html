lab-bourse — Règles de confidentialité / Privacy policy

Français

lab-bourse est une application personnelle utilisée par une seule personne, son propriétaire. Elle n'a pas d'autre utilisateur.

  • Donnée Google utilisée : une seule autorisation, gmail.send, qui permet d'envoyer un e-mail depuis le compte Gmail du propriétaire. L'application ne peut ni lire, ni modifier, ni supprimer aucun e-mail, contact ou fichier.
  • Usage : envoyer au propriétaire un e-mail quotidien qu'il a configuré lui-même.
  • Collecte : l'application ne collecte aucune donnée personnelle d'un tiers.
  • Partage : aucune donnée n'est vendue, transférée ni partagée avec un tiers.
  • Conservation : seul le jeton d'autorisation est conservé, sous forme de secret chiffré, pour permettre l'envoi. Le propriétaire peut le révoquer à tout moment depuis les réglages de sécurité de son compte Google.

L'usage des informations reçues des API Google respecte les règles de Google sur les données utilisateur des services d'API, y compris les exigences d'usage limité.

English

lab-bourse is a personal application used by a single person, its owner. It has no other user.

  • Google data used: a single permission, gmail.send, which allows sending e-mail from the owner's Gmail account. The application cannot read, modify or delete any e-mail, contact or file.
  • Purpose: sending the owner a daily e-mail that the owner configured.
  • Collection: the application collects no personal data from any third party.
  • Sharing: no data is sold, transferred or shared with any third party.
  • Retention: only the authorization token is kept, as an encrypted secret, so that the e-mail can be sent. The owner can revoke it at any time from the security settings of the Google account.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
